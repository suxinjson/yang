## 📱 手机体验与运行方式

### 方式 1：同一局域网内直接手机畅玩（最快最方便）
1. 确保手机和电脑连接同一个 Wi-Fi。
2. 打开手机浏览器（Chrome / 夸克 / 手机自带浏览器等），访问：
   ```
   http://192.168.21.83:5173/
   ```
   *(如果 IP 发生变化，在终端运行 `npm run dev` 会显示最新的局域网 IP)*
3. **添加到手机桌面（秒变独立 App）**：
   在手机浏览器菜单中点击 **“添加到主屏幕”**（Add to Home Screen）。桌面上就会出现带有爱心图标的独立 App，全屏无网址栏运行，体验和原生 App 一模一样！

## 🚀 部署到你的服务器

1. **打包静态文件**：
   ```bash
   npm run build
   ```
   打包完成后会在根目录生成 `dist/` 文件夹。
2. **上传到服务器**：
   把 `dist/` 文件夹内的所有文件上传到服务器的 Nginx、Caddy 或宝塔 Web 目录即可。
   Nginx 配置参考示例：
   ```nginx
   server {
       listen 80;
       server_name love.yourdomain.com;
       root /var/www/love-game/dist;
       index index.html;
       location / {
           try_files $uri $uri/ /index.html;
       }
   }
   ```

## 📦 打包为安卓原生 APK（可选）

如果想给她发一个真正的 `.apk` 安装包：
1. **安装 Capacitor**：
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "铁了心爱你" "com.love.tielexin"
   npm run build
   npx cap add android
   npx cap open android
   ```
2. 在打开的 Android Studio 中直接点击 **Build APK** 即可生成专属安装包发给她。
