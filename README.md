# 《钢了钢》· 专属限定消除大作战 💖

专门为对象打造的浪漫定制版“羊了个羊”堆叠三消手机游戏！以你们专属的“钢了心爱你”、“铁了心爱你”为核心命名！

## 🌟 核心特色与专属彩蛋

1. **专属定制卡牌**：
   - 🔩 **铁了心爱你**：专属专情梗卡牌
   - 🛡️ **钢了心爱你**：坚固真爱盾牌卡牌
   - 🧦 **可爱臭袜子表情包**：你们的聊天专属搞笑梗
   - 🎂 **生日合照**：记录美好瞬间
   - 👦 **超帅男朋友照片**：帅气自拍
   - 🧋 **全糖奶茶 / 啵啵贴贴 / 免死金牌** 等浪漫元素
2. **📸 游戏内【图集管理】（极度方便）**：
   - 点击游戏右上角 **「📸 图集」**，可以随时从手机相册或电脑中直接上传你们的真实照片/表情包！
   - 自动压缩与本地保存，即换即玩，无需重新编译代码。
3. **🦸‍♂️ 终极外援【召唤男朋友】**：
   - 槽位快满或陷入困境时，点击一键召唤超帅男友！
   - 专属音效 + 帅照全屏弹窗 + 甜言蜜语，直接帮你移走 3 张卡牌，并额外掉落一张【全身舒缓捏肩券】！
4. **🎁 恋爱心愿存折（兑换券系统）**：
   - 通关和救场掉落各种实体特权券（奶茶免单券、捏肩券、绝不生气免死金牌、大餐请客券）。
   - 在背包中点击可打上真实的「已向男友兑现」戳记！
5. **关卡设计**：
   - **第1关**：18–24 张、最多 3 种牌型、2 层，轻松热身
   - **第2关**：90–108 张、最多 7 种牌型、4 层，铺满棋盘的随机层叠
   - **第3关**：120–144 张、最多 8 种牌型、6 层，保留 ♥ 爱心轮廓
   - 上述为默认参数，可在后台「🎲 关卡与布局」逐关配置牌量、牌型、层数、横纵摆放范围、位置随机扰动与造型，也可调整棋盘宽高。
   - 每局随机抽取牌型、数量、位置与层叠空隙；每种牌的数量都是 3 的倍数，开局保证至少存在一条无需道具的通关路径。保存参数后在重开或下一关应用，当前牌局保持原配置和卡牌定义。
   - 棋盘以 420×540 为基准随屏幕宽度缩放，渲染和遮挡判定共用尺寸，避免窄屏裁切和误判。
6. **Web Audio API 纯代码合成音效**：
   - 点击木质音、消除风铃音、外援英雄登场乐、胜利大号角，无需下载额外 mp3 文件，全机型完美兼容。

## 📱 手机体验与运行方式

### 方式 1：同一局域网内直接手机畅玩（最快最方便）
1. 确保手机和电脑连接同一个 Wi-Fi。
2. 打开手机浏览器（Chrome / 夸克 / 手机自带浏览器等），访问：
   ```
   http://192.168.21.83:5173/
   ```
   *(如果 IP 发生变化，在终端运行 `npm run dev` 会显示最新的局域网 IP)*
3. **添加到手机桌面（秒变独立 App）**：
   在手机浏览器菜单中点击 **“添加到主屏幕”**（Add to Home Screen）。桌面上就会出现带有爱心图标的独立 App，全屏无网址栏运行，体验和原生 App 一模一样！

## 🚀 部署到你的服务器

1. **打包静态文件**：
   ```bash
   npm run build
   ```
   打包完成后会在根目录生成 `dist/` 文件夹。
2. **上传到服务器**：
   把 `dist/` 文件夹内的所有文件上传到服务器的 Nginx、Caddy 或宝塔 Web 目录即可。
   Nginx 配置参考示例：
   ```nginx
   server {
       listen 80;
       server_name love.yourdomain.com;
       root /var/www/love-game/dist;
       index index.html;
       location / {
           try_files $uri $uri/ /index.html;
       }
   }
   ```

## 📦 安卓客户端

安卓版为 `钢了钢 1.1.0`（包名 `com.love.ganglegang`），支持 Android 7.0 及以上。游戏页面与默认图片随 APK 打包，启动时自动连接 `.env.android` 中内置的后台 `https://124.70.184.136/gang`，同步关卡、照片和存折，无需用户填写服务器地址。网络不可用时使用本机已保存的配置和存折。

Windows 安装 Java 21、Android SDK 36、Build Tools 35.0.0 后运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1 -JdkPath '你的JDK目录' -SdkPath '你的Android SDK目录'
```

脚本构建前端、同步 Capacitor、生成正式签名 APK 并校验签名，产物为 `artifacts/android/ganglegang-1.1.0.apk` 和 SHA256 文件。签名密钥保存在当前 Windows 用户目录的 `.android/ganglegang-signing` 中，密码由当前 Windows 用户加密保存；请备份整个目录并保留该 Windows 账户访问权限，后续覆盖升级需要同一密钥。构建脚本不上传或发布应用。

仅同步安卓工程可运行 `npm run build:android`，然后用 Android Studio 打开现有 `android` 目录。更新内置后台地址需修改 `.env.android` 后重新打包。

## 开发验证

运行 `npm run build` 检查 Vue / TypeScript 类型和生产构建，运行 `npm test` 执行随机关卡验证、后台保存与浏览器交互测试。浏览器测试默认使用本机 Microsoft Edge；也可通过 `PLAYWRIGHT_CHANNEL=chrome` 环境变量改用本机 Chrome。

测试覆盖 300 个默认随机关卡与 64 组极端配置的边界和通关路径，以及多种屏幕宽度、三关实际点击通关、移出后撤回、消除过程中重开、后台配置恢复、失败提示和服务端鉴权。

后台入口为 `/?admin`，也可连点游戏标题五次。关卡张数允许 6–240（保存时取 3 的倍数并限制为实际容量），牌型 1–12、层数 1–8、横纵范围 60–100%、位置随机扰动 0–100%。后台会分别提示「已保存并同步到服务器」和「仅保存在本机，未同步」。同一页面保存后重开或下一关应用，其他设备刷新游戏获取已同步的新配置。服务器重启后需要重新登录后台。

后台「卡牌种类与图片」中的「男友帅照配置」支持六张照片分别改名、上传替换及恢复默认照片。支持 JPG / PNG / WebP（单张不超过 10MB），自动压缩至最长边 640 像素后保存到服务器配置。可固定一张或随机选择，名称和照片同步用于帅照卡牌与救场弹窗。修改名字后点击「保存帅照配置」或「保存并退出后台」。关闭「加入叠叠卡牌」后，后续牌局不再抽取帅照卡牌，救场功能继续可用；开启表示参与随机抽牌，并非每局必出。
