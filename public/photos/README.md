# 静态图片放置目录说明 📸

如果你想在打包部署到服务器前，就把照片永久内置进游戏（这样任何人打开游戏，无需手动上传即可看到）：

直接将你的照片或表情包文件重命名并放入本文件夹 `public/photos/` 即可：

| 文件名 | 对应卡牌 | 建议内容 |
| :--- | :--- | :--- |
| `iron_heart.png` (或 .jpg) | 铁了心爱你 | 你们的“铁了心”表情包 |
| `steel_heart.png` (或 .jpg) | 钢了心爱你 | 你们的“钢了心”表情包 |
| `sock_meme.png` (或 .jpg) | 可爱袜子表情包 | 你们聊天中的袜子表情包 |
| `birthday_photo.png` (或 .jpg) | 生日合照 | 她过生日的合照 / 庆生拍立得 |
| `boyfriend_photo.png` (或 .jpg) | 我的帅照 | 你的帅气自拍 / 搞怪照片 |
| `boba_tea.png` (或 .jpg) | 全糖奶茶 | 她常喝的奶茶实拍 |
| `hug_kiss.png` (或 .jpg) | 抱抱亲亲 | 两个人甜蜜合照或亲昵表情包 |
| `gold_card.png` (或 .jpg) | 免死金牌 | 搞怪免死金牌图片 |

> **提示**：如果不放文件，游戏会自动优雅降级显示内置的精致手绘图标；只要放入对应图片，游戏就会自动显示真实照片！
